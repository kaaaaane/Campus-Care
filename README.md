# Campus-Care

This is an elaborate step-by-step guide to opening and running your Campus-Care project in Visual Studio Code.

---

 Step 1: Open Visual Studio Code

---

Step 2: Open the `Campus-Care` Folder in VS Code

You can open the project folder using any of the following methods:

Method A (Drag and Drop):
1. Open your File Explorer to the location shown in your screenshot.
2. Drag the 'Campus-Care' folder directly into the open VS Code window.

Method B (File Menu):
1. Click 'File' in the top-left menu bar of VS Code.
2. Select 'Open Folder...' (or press `Ctrl + K`, then `Ctrl + O`).
3. Navigate to the directory containing Campus-Care', click to select the folder, and click 'Select Folder'.

Method C (Right-Click Menu in File Explorer):
1. In Windows File Explorer, right-click the 'Campus-Care' folder.
2. Select **Open with Code**.

---

Step 3: Explore Your Files in VS Code

Once the folder is open, look at the 'Explorer sidebar' on the left side of VS Code. You should see the following contents listed inside the 'Campus-Care' root directory:
 - `index.html` (Main structure of your web application)
 - `script.js` (JavaScript functionality)
 - `stye.css` (CSS stylesheet)

---

Step 4: Run/Preview the Project

Option 1: Using Live Server (Recommended)
Using an extension like 'Live Server' allows your web page to auto-reload in your browser whenever you save changes to your code.

1. Install Live Server Extension:
   > Click the 'Extensions' icon on the left activity bar (or press `Ctrl + Shift + X`).
   > Search for 'Live Server' (by Ritwick Dey).
   > Click 'Install'.

2. Launch the Web Page:
   > Open `index.html` by clicking on it in the file explorer.
   > Right-click anywhere inside the `index.html` code editor and select 'Open with Live Server' (or click 'Go Live' at the bottom-right status bar).
   > Your default web browser will automatically open showing your 'Campus-Care' web app.

Option 2: Open Directly in Browser
If you prefer not to use an extension:

1. Open the 'Campus-Care' folder in your File Explorer.
2. Double-click `index.html` (or right-click `index.html` > 'Open with' > select your preferred web browser, e.g., Chrome, Edge, Firefox).
